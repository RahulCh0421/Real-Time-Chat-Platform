# Real-Time-Chat-Platform
It is a real-time, privacy-focused chat platform designed for temporary communication. Users can join a secure chat session using a host-generated passkey and communicate through text, voice, and video.

### Features

* Passkey-based chat sessions
* Real-time messaging
* Join/leave notifications
* Screenshot & recording detection
* Automatic session/chat deletion
* No permanent storage of chat data

### Tech Stack

* React.js
* JavaScript
* WebRTC
* HTML & CSS

### Purpose

This Chat Platform focuses on providing a simple and temporary communication experience where conversations disappear rather than being permanently stored.
